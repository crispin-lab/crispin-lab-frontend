# 와이어프레임

> **이 문서의 범위**: 첫 마일스톤 화면의 저충실도 와이어프레임 + 화면별 결정 메모.
>
> **시각 방향 (정체성·색·폰트·light/dark·레이아웃 골격)**: `../rules/design.md`

본 문서는 **룰이 아닌 산출물 인덱스** — `rules/` 가 아니라 `design/` 디렉토리에 둔 이유. `.claude/CLAUDE.md` 의 `@rules/*.md` 자동 import 대상이 아니므로 Claude 의 룰 컨텍스트에 매번 끌려오지 않는다. 갱신 빈도가 잦은 산출물에 적합하고, 변경이 PR 통과 기준이 되지 않는다.

## 표현 형식

- **본 문서의 1차 표현은 ASCII / box-drawing 와이어프레임** — Markdown 코드 블록 안에 inline. 저충실도라 박스·라벨·구분선이면 의도 전달에 충분하고, `../rules/design.md` 의 레이아웃 골격 (ASCII) 과 톤이 일관.
- 그래픽 편집·코멘트·버전 히스토리가 필요해지면 **외부 도구 (Figma 또는 Excalidraw) 산출물을 추가**해 외부 링크 한 줄로 박는다. ASCII 가 source of truth, 외부 도구는 *부가* 표현.
- 이미지·스크린샷 파일은 레포에 넣지 않는다 (용량·rotation·외부 도구의 history 위임).
- 외부 링크가 깨지거나 와이어프레임이 바뀌면 같은 링크가 새 버전을 가리키게 — 별도 archive 링크를 본 문서에 누적하지 않는다.
- ASCII 안 한국어 라벨은 monospace 폰트에서 약간 misalign 될 수 있다. *배치 골격* 의도만 전달하면 OK — 픽셀 정확성은 추구하지 않는다.

## 화면별 섹션 템플릿

각 화면 섹션은 다음을 갖는다.

- **그룹** — 방문자 path / 저자 path. `../rules/design.md` 의 *두 사용자 그룹* 절 참조.
- **목적** — 한 줄. 사용자가 이 화면에 와서 *무엇을* 하는지.
- **primary action** — 이 화면의 가장 중요한 액션 1 개.
- **레이아웃** — app bar / 사이드바 / 본문 / TOC 의 배치 한 단락. 어느 영역이 비어 있는지도 명시.
- **외부 링크** — Figma 또는 Excalidraw 링크. 작성 전이면 `TBD — 작성 예정`.
- **결정 메모** — 이 화면에서 박힌 시각·UX 결정. 후속 화면 구현 PR 의 참조 지점.

화면은 **사용자 흐름 순** 으로 배치 — 방문자가 먼저 만나는 순서 → 저자가 만나는 순서. `crispin-lab` 이 *공개 위키 first* 라 방문자 path 가 01~03, 저자 path 가 04~05.

## 화면

### 01 — 공개 위키 랜딩 (방문자)

- **그룹**: 방문자 path.
- **목적**: 비특정 다수가 root `/` 로 진입했을 때 *무엇이 있는 사이트인가* 를 한눈에 파악하고, 검색 또는 추천 페이지로 진입.
- **primary action**: 검색 input 에 키워드 입력 (→ 03 검색 결과).
- **레이아웃**: 좌 사이드바 **없음**. 상단 thin app bar (로고 + 로그인 link). 본문 중심 — 큰 검색 input · 추천 페이지 list · tag cloud.

```text
┌──────────────────────────────────────────────────────────────┐
│  crispin-lab                                       로그인 →  │ ← app bar
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                                                              │
│            글이 모이는 곳                                     │
│            개인 위키 — 공개 메모와 정리                        │
│                                                              │
│            ┌──────────────────────────────────────────┐      │
│            │ 🔍  키워드로 검색                        │      │
│            └──────────────────────────────────────────┘      │
│                                                              │
│            ──────────────────────────────                    │
│                                                              │
│            최근 공개 페이지                                   │
│            · TipTap 위키 링크 구현 메모       2026-05-22     │
│            · 1Q84 (3편) 독서 정리             2026-05-19     │
│            · 데이터 중심 애플리케이션 정리     2026-05-12     │
│            · 주간 회고 — 5월 둘째 주          2026-05-10     │
│                                                              │
│            ──────────────────────────────                    │
│                                                              │
│            태그   tiptap · 독서 · 회고 · 시스템설계 ·         │
│                  next · spring · 인프라 · 메모               │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

- **외부 링크**: 필요 시 추가.
- **결정 메모**:
  - **방문자 first 정체성의 얼굴**. 진입 즉시 *무엇이 있는 사이트인가* 가 한 줄로 보이고, *어떻게 찾는가* (검색 + 추천 + 태그) 가 명확.
  - **큰 검색 input 이 primary** — Wikipedia · DuckDuckGo 의 search-first landing 정신.
  - 추천 페이지 = `visibility=PUBLIC` 페이지 중 최근 수정 N개. 백엔드 정합 메모 참조.
  - tag cloud = 사용 빈도 상위 태그 N개. `Tag(spaceId, name)` 모델은 백엔드 정의됨. across-space 집계 endpoint 는 백엔드 정합 메모 참조.
  - 로그인 link 는 app bar 오른쪽 끝 — 저자 전용 진입이라 시각 priority 낮음.
  - 좌 사이드바 없음 — 방문자에게 페이지 트리는 noise (`../rules/design.md` 의 *방문자 path 에 저자 UI 흘러듦* 회피).

### 02 — 공개 페이지 reading (방문자)

- **그룹**: 방문자 path.
- **목적**: 공유 링크 또는 검색 엔진으로 `/pages/[pageId]` 진입한 비로그인 방문자가 본문을 *잘 읽는다*.
- **primary action**: 읽기 (보조: `[[페이지명]]` 클릭 → 다른 페이지 진입, 검색).
- **레이아웃**: 좌 사이드바 **없음**. 상단 thin app bar (검색·로그인 link). 본문 max-w ~720px · 한 줄 80~90자 · 본문 위 메타 줄 (저자·날짜·visibility) · 본문 하단 인바운드 links · 옵션 우측 TOC.

```text
┌──────────────────────────────────────────────────────────────┐
│  crispin-lab  [🔍 검색 ──────────]                로그인 →   │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│            # TipTap 위키 링크 구현 메모                       │
│            crispin · 2026-05-22 · 🌐 PUBLIC                   │
│                                                              │
│            ─────────────                                     │
│                                                              │
│            본 페이지는 [[회의록]] 에서 파생됐다. TipTap      │
│            의 mention 확장으로 `[[` 트리거를 잡고…            │
│                                                              │
│            ## 노드 구조                                      │
│            ...                                               │
│                                                              │
│            ## 백엔드 매핑                                    │
│            ...                                               │
│                                                              │
│            ─────────────                                     │
│            ← 이 페이지로 들어오는 링크                         │
│              · 주간 회고 — 5월 둘째 주                        │
│              · 아이디어 모음                                   │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

- **외부 링크**: 필요 시 추가.
- **결정 메모**:
  - **본문 위 메타 줄 = 신뢰 신호** (`../rules/design.md` 의 *신뢰 신호 노출* 정합). 저자 · 발행/수정 날짜 · visibility 아이콘 (`🌐 PUBLIC`, `👥 INTERNAL`, `🔒 PRIVATE`). 비로그인 방문자가 `🔒 PRIVATE` 페이지에 접근 시도하면 404 (존재 자체 노출 안 함, `../rules/auth.md` 정신).
  - **본문 하단 인바운드 links** — 본 페이지를 `[[페이지명]]` 으로 가리키는 다른 페이지. 위키 정신의 핵심 — 글이 *섬* 이 아니라 *그래프*. 백엔드 `PageLink` 모델로 query (`pageId` 가 target 인 links). 백엔드 정합 메모 참조.
  - **우측 TOC 는 옵션** — heading 3개 이상이거나 본문 길이 일정 이상일 때만. 짧은 페이지엔 미표시 (시각 무게 회피).
  - `[[페이지명]]` chip = `bg-accent text-accent-foreground` — 본문 안 *유일한 accent*. 다른 강조 없음.
  - 편집 link · 사이드바 등 *저자 UI 부재* — 비로그인 방문자에겐 노출 X. 본인이 로그인 상태면 우측 상단 또는 본문 메타 줄 옆에 *편집* link 한 줄 (05 진입).

### 03 — 검색 결과 (방문자 + 저자 공통)

- **그룹**: 방문자 + 저자 공통.
- **목적**: 검색 input 의 키워드로 페이지·태그·스페이스 검색 결과.
- **primary action**: 결과 항목 클릭 → 02 공개 페이지 reading (저자면 05 편집).
- **레이아웃**: 좌 사이드바 **없음** (방문자 일관성). 상단 app bar 의 검색 input expanded. 본문은 필터 dropdown 3개 + 결과 list-row.

```text
┌──────────────────────────────────────────────────────────────┐
│  crispin-lab  [🔍 위키 ___________________ ⌫]    로그인 →    │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│     "위키" — 결과 8건                                        │
│                                                              │
│     [ 스페이스 ▾ ]   [ 태그 ▾ ]   [ 정렬 ▾ ]                 │
│                                                              │
│     ──────────────────────────────────────────              │
│     📄  TipTap 위키 링크 구현 메모                            │
│         개인 노트 · 2026-05-22 · 🌐                           │
│     ──────────────────────────────────────────              │
│     📄  주간 회고 — 5월 둘째 주                               │
│         업무 · 2026-05-10 · 🌐                                │
│     ──────────────────────────────────────────              │
│     📄  아이디어 모음                                         │
│         개인 노트 · 2026-04-30 · 🌐                           │
│     ──────────────────────────────────────────              │
│                                                              │
│     [ 더 보기 ]                                               │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

- **외부 링크**: 필요 시 추가.
- **결정 메모**:
  - 결과 항목 = 제목 · 스페이스 · updatedAt · visibility 아이콘 (백엔드 `PageSearching` 응답 `pageId`/`spaceId`/`title`/`updatedAt` 정합 + visibility 는 응답 필드 또는 별도 조회).
  - **방문자 검색** = `visibility=PUBLIC` 만 결과에 노출 (비로그인 권한 정합). **저자 검색** = INTERNAL · PRIVATE 까지. 백엔드 query 가 인증 컨텍스트로 분기 (`../rules/auth.md`).
  - 필터 = dropdown 3개 — 스페이스 / 태그 / 정렬 (백엔드 `GET /v1/pages?space=...&tag=...&sort=...` 정합). 사이드 panel 형 advanced filter 는 *reading-friendly 미니멀* 에 어긋남.
  - 좌 사이드바 없음 — 방문자 일관성. 저자가 본 화면에 들어와도 사이드바 미표시 (탐색은 검색 자체가 primary).
  - snippet (매칭 highlight) 은 백엔드 응답에 없음 — 백엔드 정합 메모 참조.

### 04 — 로그인 / 회원가입 (저자 진입)

- **그룹**: 저자 path 진입점.
- **목적**: 저자가 편집·관리를 위해 인증.
- **primary action**: 로그인 (가입 폼은 secondary).
- **레이아웃**: app bar **없음** (인증 흐름 분리). 본문 단일 카드 중앙 배치. 좁은 max-w (~360~400px).

```text
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│                                                              │
│                                                              │
│                ┌────────────────────────┐                    │
│                │  crispin-lab           │                    │
│                │                        │                    │
│                │  email                 │                    │
│                │  ┌──────────────────┐  │                    │
│                │  └──────────────────┘  │                    │
│                │                        │                    │
│                │  password              │                    │
│                │  ┌──────────────────┐  │                    │
│                │  └──────────────────┘  │                    │
│                │                        │                    │
│                │  [    로그인    ]      │  ← primary         │
│                │                        │                    │
│                │  계정이 없으신가요?    │                    │
│                │  회원가입 →            │  ← secondary       │
│                └────────────────────────┘                    │
│                                                              │
│                ← 위키로 돌아가기                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

- **외부 링크**: 필요 시 추가.
- **결정 메모**:
  - **저자 전용 진입**. 비로그인 방문자가 `/` 또는 `/pages/[pageId]` 로 들어오면 본 화면 X (각각 01, 02 가 정상 진입). `/login` 으로 명시 진입한 사용자만 본다.
  - app bar 없음 — 인증 흐름 분리 정신. *위키로 돌아가기* link 한 줄로 탈출 경로 보장.
  - 카드 좁은 폭 (~360~400px) — 시각 집중 + 모바일 대비.
  - 가입은 secondary 텍스트 링크. accent 안 씀 — 로그인이 primary 라 강조 충돌 회피 (`../rules/design.md` 의 *accent 1~2 군데*).
  - 로그인 입력 = email + password (백엔드 `POST /v1/auth/login` 정합). 회원가입 입력 = email + handle + password (백엔드 `POST /v1/users` 정합, `handle` 은 3~30자 소문자/숫자/`_`).
  - 로그인 성공 후 진입 = redirect query (`?redirect=...`) 또는 root `/` (랜딩). `../rules/auth.md` 의 401 처리 흐름과 정합.

### 05 — 저자 페이지 편집 (저자 workspace)

- **그룹**: 저자 path.
- **목적**: 저자가 페이지 본문을 작성·수정·트리 정리.
- **primary action**: 본문 편집 (TipTap 에디터). 보조: 저장, visibility 변경, 트리 이동.
- **레이아웃**: 좌 사이드바 (페이지 트리) + 본문 (편집 모드). 상단 thin app bar (검색·계정·테마 토글).

```text
┌──────────────────────────────────────────────────────────────┐
│ crispin-lab  [🔍 검색 ──────────]            🌗  [👤 계정]    │
├──────────────┬───────────────────────────────────────────────┤
│              │  개인 노트 › 아이디어  🌐 PUBLIC               │ ← breadcrumb + visibility
│  개인 노트   │  ┌─────────────────────────────────────────┐ │
│              │  │                                         │ │
│  ▼ 개인 노트 │  │  # TipTap 위키 링크                     │ │
│    회의록    │  │                                         │ │
│  ▶ 아이디어  │  │  본 페이지는 [[회의록]] 에서 파생됐다.  │ │ ← accent chip
│    ▼ 독서    │  │                                         │ │
│      1Q84    │  │  ## 메모                                │ │
│              │  │  - 첫 단락…                             │ │
│  ▷ 업무      │  │                                         │ │
│              │  │  (max-w ~720px · 한 줄 80~90자)         │ │
│              │  │                                         │ │
│              │  └─────────────────────────────────────────┘ │
│              │  [ 저장 ]   v3 · 2026-05-26 14:32             │
└──────────────┴───────────────────────────────────────────────┘
```

- **외부 링크**: 필요 시 추가.
- **결정 메모**:
  - **저자 mode** — 같은 URL (`/pages/[pageId]`) 의 *편집 권한* view. 비로그인은 02 reading 으로 fall-through.
  - **현재 페이지 = 사이드바 accent** (`▶ 아이디어`) + 본문 위키 chip = 본 화면 accent 2 군데 (상한).
  - **breadcrumb + visibility** 본문 상단 — 어디 있는지 + 누가 볼 수 있는지. visibility 클릭 시 dropdown 으로 PUBLIC / INTERNAL / PRIVATE 변경.
  - **에디터 toolbar = floating bubble** (선택 시점에만 등장). 상단 sticky toolbar 는 본문 너비를 차지해 *글 중심* 시각 정합에 어긋남.
  - **명시 저장 (자동 저장 X)** — 백엔드는 draft / autosave endpoint 가 없고 `PUT /v1/pages/{id}` 호출 시점에만 `PageRevision` 이 생성된다. 본문 아래 인디케이터는 *마지막 명시 저장 시점 + 현재 버전* (`v3 · 2026-05-26 14:32`). 자동 저장은 백엔드 확장 후 별도 도입.
  - `[[페이지명]]` = inline chip, `bg-accent text-accent-foreground` (`../rules/editor.md` 의 *렌더링* 절과 정합). 백엔드는 `PageLink(pageId, revisionId, target, type)` 로 저장 + `ExtractedWikiLink` 로 추출.
  - **사이드바 페이지 트리** — 백엔드는 트리 endpoint 가 없어 클라이언트가 `GET /v1/pages?spaceId=...` 의 flat 결과를 `parentPageId` 로 재구성. 백엔드 정합 메모 참조.

## 백엔드 정합 메모

본 와이어프레임은 백엔드 (`crispin-lab-backend`) 의 현재 도메인 모델 / Controller 와 정합 검증을 거쳤다 (검증 시점: LAB-60 작업 시).

| 와이어프레임 항목 | 백엔드 상태 | 후속 |
|---|---|---|
| 01 랜딩의 **최근 공개 페이지** | `GET /v1/pages?sort=updated_at&visibility=PUBLIC` 같은 across-space + visibility 필터 endpoint **명시 없음** (`PageSearching` 은 keyword 검색 중심) | 백엔드에 across-space + visibility 필터 endpoint 추가 또는 `PageSearching` 확장. |
| 01 랜딩의 **tag cloud (사용 빈도 상위)** | `PageTag` 모델은 있지만 *across-space tag 집계 endpoint* 미구현 | 백엔드에 tag 집계 API 추가. |
| 02 페이지 reading 의 **인바운드 links** (이 페이지를 가리키는 다른 페이지 list) | `PageLink` 모델은 있지만 *target 으로 query* 하는 endpoint 미구현. 현재는 *outgoing* 만. | 백엔드에 `GET /v1/pages/{id}/inbound` 같은 endpoint 추가. |
| 02 의 **visibility 권한 분기** (비로그인은 PUBLIC 만, 저자는 모두) | `../rules/auth.md` 의 옵셔널 인증 endpoint 흐름과 정합. 백엔드의 `PageGetting` 이 visibility + 권한 분기를 처리하는지는 별도 확인 필요. | 백엔드의 visibility 권한 정책 확인 + 정합 시 명시. |
| 02 / 03 / 05 의 **visibility 아이콘** | 백엔드 응답에 `visibility: PUBLIC / INTERNAL / PRIVATE` 포함 (`Page`, `Space` 모두) | 정합. |
| 03 검색 결과의 **snippet (매칭 highlight)** | `PageSearching` 응답에 snippet 필드 **없음** | 백엔드 응답 확장 또는 클라이언트 본문 별도 조회. |
| 03 의 **카테고리 / 필터 명명** | 도메인에 "카테고리" 개념 없음 — `Tag` 가 그 역할 | "카테고리" → "태그" 명명 통일. `GET /v1/pages?tag=...` 정합. |
| 04 의 **로그인 / 가입 입력** | `POST /v1/auth/login` = email + password / `POST /v1/users` = email + handle + password | 정합. |
| 05 의 **사이드바 페이지 트리** | `GET /v1/spaces/{id}` 가 페이지 미포함, `GET /v1/pages?spaceId=...` 는 flat 검색만 | 클라이언트가 `parentPageId` 로 재구성 또는 백엔드에 트리 API 추가. |
| 05 의 **breadcrumb path** | `GET /v1/pages/{id}` 응답에 `parentPageId` 만, 전체 경로 없음 | 클라이언트 재귀 조회 또는 백엔드 응답에 `path` 배열 추가. |
| 05 의 **자동 저장** | draft / autosave endpoint **없음**. `PageRevision` 은 명시 `PUT /v1/pages/{id}` 시점에만 생성 | 자동 저장 필요 시 백엔드 확장. 현재 와이어프레임은 *명시 저장 + version 표시*. |
| 05 의 `[[페이지명]]` **위키 링크** | `PageLink(pageId, revisionId, target, type)` 저장 + `ExtractedWikiLink` 추출 | 정합. |
| 05 의 **PageRevision 히스토리** | `GET /v1/pages/{id}/revisions` 와 `GET /v1/pages/{id}/revisions/{revId}` 구현 | 와이어프레임 미표시 — 본 마일스톤 범위 외. 추후 "히스토리 보기" UI 결정 시 추가. |

본 표는 *현재 백엔드 기준* 의 스냅샷이다. 백엔드가 진화하면 (예: across-space query, 인바운드 links endpoint, tag 집계, 페이지 트리 API 도입) 본 표의 해당 행을 갱신.

## 갱신·교체 정책

- **링크 깨짐**: 발견 시 같은 PR 에서 새 링크 또는 `TBD — <사유>` placeholder 로 교체.
- **결정 변경**: *결정 메모* 만 갱신하고 외부 링크는 새 버전으로 (히스토리는 외부 도구 위임). archive 링크 누적 금지.
- **룰에 영향 주는 결정**: 와이어프레임 작업 중 시각 룰을 바꿀 만한 결정이 박히면 같은 PR 에서 `../rules/design.md` 의 해당 절도 갱신.

## 본 문서가 책임지지 않는 것

LAB-60 티켓의 제외 항목 그대로 — 본 문서는 다루지 않는다.

- **고충실도 시안** (픽셀 단위 색·여백 결정) — 도메인 화면 구현 PR 안에서 흡수.
- **디자인 시스템 토큰 별도 정의** — shadcn/ui 의 CSS 변수로 충분, 부족할 때 도입.
- **마케팅 페이지 / 랜딩** — 01 *공개 위키 랜딩* 은 마케팅 페이지가 아니라 *위키 자체의 진입 화면*. 마케팅·홍보 페이지는 별도 도메인.
- **모바일 전용 레이아웃** — 데스크톱 우선, 반응형은 점진 도입.
- **저자 홈 / 내 스페이스 list** — 본 마일스톤은 *저자 path = 페이지 편집* 만 다룸. 저자가 자신의 스페이스·페이지를 일람하는 화면은 후속 티켓.
